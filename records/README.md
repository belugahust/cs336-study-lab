# 数据记录说明

`sessions.jsonl` 是学习与实验记录的原始数据，一行一个事件，包含唯一 ID 和 UTC+8 时间戳。`summary.csv` 是自动导出的表格，不要把 CSV 当主数据修改。

- `kind=session`：讲次、本次分钟数、收获、疑问、视频链接、看完视频/完成本讲练习两种独立标记。
- `kind=experiment`：作业号、实验名、指标、配置说明、seed、设备和总结。
- 同一讲可以多次记录，分钟数累计；看完/练习标记一旦记录即保持。
- 填错时先备份，再编辑对应 JSON 行或删除误记的一行，运行 `python study.py render`，再同步。时间、指标和状态不能凭空编造。
- 学习笔记、指标与记录会随公开仓库公开；不要填写个人隐私、密钥或受限数据。
